# Rainy Watch Face

A Wear OS watch face that tells the time in words and answers one question: will it rain today?

  <img src="docs/face-london.png" width="30%" alt="Seven forty-two in the 12-hour mode, rain in London from 8 PM, on a purple background">
  <img src="docs/face-paris.png" width="30%" alt="Fourteen fifty-five, rain in Paris from 15:00 to 17:00, on an orange background">
</p>

- The time as words ("Ten oh eight."), in English, Italian, French, Spanish, German, Romanian and Hindi, following the
  watch's 12/24-hour setting.
- The rain answer under the time: from the [Rainy](https://play.google.com/store/apps/details?id=app.wakirox.rainy)
  app's complication when it's installed ("London · DRY · Until 23:00"), from the watch's own weather otherwise.
- Tilted for the left or the right wrist, or straight.
- Two arcs for any complication (steps and battery by default) and a circle (sunrise / sunset by default).
- Ten text colours and ten backgrounds; always-on is black, light or bold.

It is a [Watch Face Format](https://developer.android.com/training/wearables/wff) face (version 5, so Wear OS 7 /
API 37 and up): resources only, no code, no permissions, and nothing leaves the watch.

## Installing

From Google Play (`app.wakirox.rainy.watchface`), or sideloaded from a computer with the steps below.

### Sideloading, step by step

You need a watch on Wear OS 7 or later (Settings → System → About → Versions), a computer on the same Wi-Fi, and
about ten minutes.

1. **Get adb on the computer.** Download Google's
   [SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) for your system and unzip it. Open
   a terminal in the unzipped `platform-tools` folder (on macOS and Linux, type `./adb` instead of `adb` below).
2. **Get the face.** Download the `.apk` file from this repo's
   [Releases](https://github.com/wakirox/rainy-watchface/releases) page into the same folder.
3. **Turn on developer options on the watch.** Settings → System → About → Versions, then tap **Build number** seven
   times until the watch says you're a developer. (On some watches it's Settings → About watch → Software →
   Software version.)
4. **Turn on wireless debugging.** Settings → Developer options: turn on **ADB debugging**, then **Wireless
   debugging**. Keep the watch on the same Wi-Fi as the computer.
5. **Pair the computer.** In Wireless debugging, tap **Pair new device**. The watch shows an address like
   `192.168.x.x:37123` and a six-digit code. On the computer, run `adb pair 192.168.x.x:37123` (your address) and
   type the code.
6. **Connect.** Back on the Wireless debugging screen, the watch shows another address with a different port, under
   **IP address & Port**. Run `adb connect 192.168.x.x:41011` (that address).
7. **Install.** Run `adb install rainy-watchface-1.0.0.apk` (the file's name). It prints `Success`.
8. **Pick the face.** Long-press the watch face, swipe to the end, tap **Add**, and choose **Rainy**.
9. **Turn wireless debugging off** again in Developer options: it uses battery.

**Updating:** download the new `.apk`, repeat steps 4, 6 and 7 with `adb install -r` (pairing is remembered), and turn
wireless debugging off. **Removing:** long-press the face, or run `adb uninstall app.wakirox.rainy.watchface`.

A sideloaded copy and the Google Play copy are signed with different keys, so one can't update the other: uninstall
the one you have before installing the other. For the Rainy forecast on the face, install the
[Rainy](https://play.google.com/store/apps/details?id=app.wakirox.rainy) watch app too and pick it in the face's
weather slot; without it the face shows the watch's own weather.

## Building

The face's sources in `watchface/src/main` are generated by `tools/generate.py` from `tools/time_words.json` (the time
words, see `tools/TIME_WORDS.md`), `tools/app_strings.json` (words shared with the Rainy app) and Google Sans Flex in
`fonts/`. Never edit them by hand: change the script or the words and run it again.

```bash
uv run --no-project --with fonttools==4.66.1 python tools/generate.py           # write the face
uv run --no-project --with fonttools==4.66.1 python tools/generate.py --check   # the files on disk are up to date
tools/build.sh --serial emulator-5554                    # build with aapt2 and set it as the face, in seconds
./gradlew :watchface:installDebug                        # or with Gradle
./gradlew :watchface:validateDebugWatchFace              # Google's validator on the debug APK
./gradlew :watchface:bundleRelease                       # the Play bundle
```

`generate.py` also checks the layout (no slot's touch area reaches another slot's drawing in any orientation, the arcs'
bands hold their drawing) and that the sample arc texts fit. Its docstring lists what the Watch Face Format runtime
does in practice.

`validate<Variant>WatchFace` runs Google's Watch Face Push validator, the most complete one Google publishes: the Watch
Face Format schema, the memory footprint (10 MB ambient, 100 MB interactive), the APK's contents, the format version
property, the minimum SDK and the signature. Its one Push-only check, the package name, fails by design and is
ignored. A signed `bundleRelease` validates its APK first.

Release builds are signed with the key in `keystore.properties` at the repo root (gitignored: `storeFile`,
`storePassword`, `keyAlias`, `keyPassword`); without it they are unsigned.

## Publishing

With [Gradle Play Publisher](https://github.com/Triple-T/gradle-play-publisher): credentials from
`ANDROID_PUBLISHER_CREDENTIALS` or `play-credentials.json` at the repo root (gitignored).

```bash
./gradlew :watchface:publishReleaseBundle    # upload to the internal track
./gradlew :watchface:promoteReleaseArtifact --from-track internal --promote-track production
```

Bump `face.versionCode` and `face.versionName` in `gradle.properties` for every release. The release notes are in
`watchface/src/release/play/release-notes/en-US/default.txt` (500 characters at most).
